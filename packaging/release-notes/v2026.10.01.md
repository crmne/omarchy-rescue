Omarchy Rescue now runs on a real laptop, not just in virtual machines. This release makes the console easier to find your way around: change the keyboard layout in one command, and see every key binding on **C-Space ?**.

**Download** `omarchy-rescue-2026.10.01-x86_64.iso` below and write it to a USB stick. With [Caligula](https://github.com/ifd3f/caligula), which also checks the download:

```bash
caligula burn omarchy-rescue-2026.10.01-x86_64.iso -s "$(cut -d' ' -f1 omarchy-rescue-2026.10.01-x86_64.iso.sha256)"
```

On macOS or Windows, see [Put it on a USB stick](https://github.com/crmne/omarchy-rescue#put-it-on-a-usb-stick).

## New

- **Change the keyboard layout.** The console starts with a US layout. `omarchy-rescue-keyboard` lets you pick another from a list, or takes one by name (`omarchy-rescue-keyboard de`), and switches the console without losing your session. It's on the welcome screen and in the `omarchy-rescue` menu. By @crmne.

## Fixed

- **C-Space ? lists the key bindings.** It showed an empty list. It now shows every binding, Omarchy's and the rescue ones, and the welcome screen and status bar point to it. By @crmne.

  ![The key binding list](https://raw.githubusercontent.com/crmne/omarchy-rescue/v2026.10.01/docs/screenshots/keybindings.png)

## Known limitations

- Codex needs device code sign-in turned on in your ChatGPT security settings, or its sign-in page refuses the code.
- The phone has to be on the same network as the rescue machine. Offline, the QR code falls back to the link itself.
- Wi-Fi is not joined automatically: run `impala` and enter the password.
- `omarchy-rescue-share` serves a root shell over plain HTTP on the local network, behind a random address. Stop it with `omarchy-rescue-share stop` when done.
- x86_64 only.
