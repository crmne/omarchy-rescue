## New

- **Sign in from your phone, both ways.** As soon as an agent prints its sign-in link, `omarchy-rescue-login` shows a QR code. Scan it and your phone opens a page that takes you to the sign-in and has a box for the code the agent wants back. Send it, and the code is typed at the console's prompt; press Enter there to use it. The page lives on the rescue machine, on your local network, behind a random address, and stops after one paste. **C-Space u** does the same for any link on screen. By @crmne.

## Fixed

- **Claude Code signs in once.** The sign-in helper had you sign in twice, and the second link never reached the phone. It now starts Claude Code directly and hands the link from its first run to the phone. By @crmne.
- **Claude Code's sign-in link fits a QR code on any screen.** The QR code now carries the short address of the handoff page, not the long link itself. By @crmne.

## Known limitations

- The phone has to be on the same network as the rescue machine. Offline, the QR code falls back to the link itself.
- `omarchy-rescue-share` serves a root shell over plain HTTP on the local network, behind a random address. Stop it with `omarchy-rescue-share stop` when done.
- The console keyboard layout is US.
- Tested in QEMU virtual machines, not yet on real hardware. x86_64 only.
